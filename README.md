# ✂️ АС «Онлайн-запись в парикмахерской»

[![Документация](https://img.shields.io/badge/📖_База_знаний-Открыть_Wiki-blueviolet?style=for-the-badge&logo=github)](https://github.com/Grenka-K/online-booking-wiki/wiki)

## 💡 О проекте

**Проблема:** Бумажный журнал приводит к накладкам, двойным записям и перегрузке администратора телефонными звонками.
**Решение:** Веб-приложение и мобильный интерфейс для онлайн-записи 24/7, которые автоматизируют расписание и снижают нагрузку на персонал.

## 📊 Бизнес-цели

*   Перевести **30%** записей в онлайн.
*   Снизить нагрузку на администратора на **50%**.
*   Уменьшить неявки клиентов на **20%**.

## 🛠 Мой вклад и инструментарий (Role: System Analyst)

В рамках этого проекта я выполнил полный цикл предпроектного анализа и проектирования:
*   **Сбор требований:** Проведение глубинных интервью (Владелец, Админ, Разработчик) и анкетирование (Клиенты, Мастера).
*   **Моделирование:** Построение BPMN-схем, DFD и ER-диаграмм.
*   **Управление требованиями:** Составление ТЗ по ГОСТ 34.602-2020, написание User Stories (INVEST) и Use Cases.
*   **UX/UI Дизайн:** Создание Low-Fi эскизов и интерактивных High-Fi прототипов (веб и мобайл).
*   **Тестирование:** Разработка матрицы трассировки (RTM), чек-листов и QA-отчета (поиск багов).

## 💻 Технологический стек (проектный)

*   **Backend:** Python (Django/FastAPI)
*   **Database:** PostgreSQL
*   **Frontend:** React / Мобильное приложение
*   **Cloud:** Yandex.Cloud (соответствие 152-ФЗ)
*   **Интеграции:** API MAX, 1С
