# 🗂️ База знаний: АС «Онлайн-запись в парикмахерской»

[![Wiki](https://img.shields.io/badge/Полная%20документация-Wiki-blue?style=for-the-badge&logo=github)](https://github.com/Grenka-K/online-booking-wiki/wiki)

Добро пожаловать в репозиторий проекта! Здесь собраны все материалы: от предпроектного анализа до архитектурных схем.

### 📌 О проекте
Проект разработан для малого бизнеса (салон красоты) с целью автоматизации процессов записи клиентов, снижения нагрузки на администратора и исключения накладок в расписании.

### 🛠️ Методологии и стек
*   **Анализ и моделирование:** User Stories, Use Cases, MoSCoW, BPMN, DFD, ER-моделирование.
*   **Стандарты:** ГОСТ 34.602-2020, Федеральный закон № 152-ФЗ.
*   **Технологии (план):** Python (FastAPI), PostgreSQL, Yandex.Cloud.
