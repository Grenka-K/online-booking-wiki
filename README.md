# 🚀 АС «Онлайн-запись в парикмахерской»

[![Wiki](https://img.shields.io/badge/Документация-Wiki-blueviolet?style=for-the-badge&logo=github)](https://github.com/Grenka-K/online-booking-wiki/wiki)

## 💡 О проекте
Разработка автоматизированной системы для малого бизнеса (салон красоты). 
**Проблема:** Бумажный журнал приводит к накладкам, двойным записям и перегрузке администратора звонками.
**Решение:** Веб-приложение для онлайн-записи 24/7, которое автоматизирует расписание и снижает нагрузку на персонал.

## 📊 Бизнес-цели
*   Перевести **30%** записей в онлайн.
*   Снизить нагрузку на администратора на **50%**.
*   Уменьшить неявки клиентов на **20%**.

## 🛠️ Мой вклад и инструментарий (Role: System Analyst)
В рамках этого проекта я выполнил полный цикл предпроектного анализа и проектирования:
*   **Сбор требований:** Проведение глубинных интервью (Владелец, Админ, Разработчик) и анкетирование (Клиенты, Мастера).
*   **Моделирование:** Построение BPMN-схем, DFD и ER-диаграмм.
*   **Управление требованиями:** Составление ТЗ по ГОСТ 34.602-2020, написание User Stories (INVEST) и Use Cases.
*   **Тестирование:** Разработка матрицы трассировки (RTM) и тест-кейсов.
