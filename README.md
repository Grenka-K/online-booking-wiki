# 🗂️ База знаний: АС «Онлайн-запись в парикмахерской»

[![Wiki](https://img.shields.io/badge/Wiki-Открыть-blue?style=for-the-badge&logo=github)](https://github.com/Grenka-K/online-booking-wiki/wiki)

Данный репозиторий содержит полный комплект проектной документации, требования и архитектурные модели для автоматизированной системы онлайн-записи.

### 📌 О проекте
Проект разработан для малого бизнеса (салон красоты) с целью автоматизации процессов записи клиентов, снижения нагрузки на администратора и исключения накладок в расписании.

### 🛠️ Инструментарий и стек
*   **Методологии:** Agile, User Stories, Use Cases, MoSCoW, BPMN, DFD, ER-modeling.
*   **Стандарты:** ГОСТ 34.602-2020, Федеральный закон № 152-ФЗ.
*   **Технологии (план):** Python (FastAPI), PostgreSQL, Yandex.Cloud.

### 📁 Структура репозитория
*   📄 **[Wiki-пространство](https://github.com/Grenka-K/online-booking-wiki/wiki)** — основная база знаний (Требования, Архитектура, Тестирование).
*   📂 **`/docs`** — исходные файлы документации (ТЗ, отчеты, презентации в формате `.docx` / `.pptx`).
