# 💻 02. Высокодетализированные прототипы (High-Fi)

В этой папке собраны интерактивные прототипы системы онлайн-записи, полностью готовые к демонстрации. Они реализованы на стеке HTML + CSS + JavaScript в виде единого файла (SPA — Single Page Application), что позволяет открывать их в любом браузере без установки дополнительного ПО.

---

### 📁 Файлы в этой папке:

| Файл | Описание |
| :--- | :--- |
| 📱 **[mobile_app.html](./mobile_app.html)** | Мобильная версия приложения (виджет телефона). Включает сценарии для клиента (запись, отзывы) и мастера (управление расписанием, перерывы). |
| 🖥️ **[pc_site.html](./pc_site.html)** | ПК-версия (полноценный сайт). Включает лендинг с разделом «Наши услуги» и «Мастера», модальное окно записи (в две колонки) и CRM-дашборд для мастера. |

---

### 🚀 Как протестировать:

1. Нажмите на любой из файлов выше (например, `mobile_app.html`).
2. В правом верхнем углу нажмите кнопку **Download raw file** (иконка скачивания `⬇️`).
3. Откройте скачанный файл на вашем компьютере двойным кликом (он откроется в вашем браузере).

---

### 🔑 Тестовые данные для входа (в роли Мастера):
В обоих прототипах при входе в кабинет мастера требуется ввести любой номер телефона и один из паролей:
*   **Иван**: `0001`
*   **Анна**: `0002`
*   **Олег**: `0003`

> 💡 *Для демонстрации системы отзывов: запишитесь как клиент, зайдите как мастер и нажмите «Выполнено», затем вернитесь в «Мои записи» клиента и оставьте отзыв.*
