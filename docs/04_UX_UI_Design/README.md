# 🎨 04. UX/UI Дизайн и Прототипирование

В этом разделе собраны материалы по проектированию пользовательского опыта (UX) и интерфейсов (UI) для системы онлайн-записи. Работа включает в себя создание эскизов, интерактивных прототипов и экспертную оценку качества.

---

### 📁 Структура раздела:

| Артефакт | Описание |
| :--- | :--- |
| 📐 **[01. Низкодетализированные эскизы (Wireframes)](./01_Low-Fi/README.md)** | Структурно-функциональные схемы (ASCII-графика). Показывают расположение элементов, навигацию и логику экранов без цветов. |
| 💻 **[02. Высокодетализированные прототипы (High-Fi)](./02_High-Fi/README.md)** | Интерактивные прототипы на HTML/JS/CSS. Включают мобильную версию (для клиентов и мастеров) и ПК-версию (лендинг + дашборд). |
| 🧪 **[03. Отчет о качестве интерфейса (QA Report)](./03_quality/README.md)** | Экспертная оценка эргономики по стандарту ISO/IEC 25010, чек-лист аудита, тест-кейсы и зафиксированные дефекты. |

---

### 🚀 Ключевые особенности раздела:

- **Модульность:** Прототипы реализованы в виде единого файла (HTML + CSS + JS), но с четким разделением логики на функции рендеринга (`renderCalendar`, `renderTimeSlots`).
- **Интерактивность:** Высокодетализированные макеты полностью кликабельны. Реализована фильтрация мастеров по услугам, защита от двойных записей, валидация полей и маски ввода телефона.
- **Динамика:** Внедрена система отзывов. Клиент может оценить мастера после визита, а средний рейтинг автоматически пересчитывается и отображается на главной странице.
- **Безопасность:** Во всех формах записи реализовано обязательное согласие на обработку персональных данных (152-ФЗ) и опциональная галочка на получение рекламных рассылок.
- **Соответствие стандартам:** Прототипы прошли аудит по эвристикам Нильсена. Выявленные дефекты (BUG-01, BUG-02) были исправлены в финальной версии кода.

> 💡 *Для просмотра интерактивных прототипов скачайте `.html` файлы из папки `02_High-Fi` и откройте их в любом браузере (Chrome, Яндекс, Edge).*
