# Низкодетализированные эскизы (Wireframes)

**Цель:** показать структуру, расположение элементов и навигацию без цветов и деталей дизайна. 
**Инструменты:** текстовый редактор, draw.io

## Эскиз 1. Экран выбора услуги и мастера (Клиент — US-01)

```text
[ < Назад ] (Вывод на главную страницу)        Онлайн запись

1. Выберите услугу:
[ Стрижка, (нажмите, чтобы изменить) v ]  <--(При нажатии можно выбрать услугу)

2.Выберите мастера: <--(При нажатии выбранный мастер подсвечивается )

      Фото                         Фото                         Фото
      Иван                         Анна                         Олег
     5.0 ⭐                       4.8 ⭐                       4.9 ⭐

3. Выберите время (на 24 октября): <--(При нажатии можно выбрать время)

[ 24 Окт, Пн (нажмите, чтобы изменить) v ]

Утро:  [ 10:00 ]  [ 11:30 ]  [ 12:00 ]

День:  [ 14:00 ]  [ 15:00 ]  [ ЗАНЯТО ] <--(При нажатии время подсвечивается)

Вечер: [ 18:00 ]  [ 19:30 ]  [ 20:00 ]
                  (Вывод на страницу "Подтверждение") -> [ ПРОДОЛЖИТЬ > ]
```

## Эскиз 2. Подтверждение записи (Клиент — US-01)

```text
[ < Назад ] <--(Вывод на страницу "Онлайн запись")     Подтверждение

Ваша запись:
Услуга:  Стрижка
Мастер:  Иван
Время:   24 октября, 15:00
Цена:    1500 руб.


 Ваше имя:
[ Введите имя...   ]       (Если не ввести имя, кнопка "записаться" не работает)


 Телефон:
[ +7 (___) ___-__-__ ]     (Если не ввести номер, кнопка "записаться" не работает)


 [x] Я даю согласие на обработку моих персональных данных (152-ФЗ)
         (Если не дать согласие, кнопка "записаться" не работает)

(Вывод на страницу "Вы записаны") ->   [ ЗАПИСАТЬСЯ ]

```
## Эскиз 3. Рабочее место мастера (Для парикмахера — US-05)

```text
👤 Мастер Иван     [ Мое расписание ]                     Выйти
                                          (Вывод на главную страницу)

Сегодня, 24 октября

10:00 | Клиент: Анна
      | Услуга: Стрижка
      | Статус: [ ВЫПОЛНЕНО ✅ ]
(При нажатии загорается зеленым цветом, "отменить" пропадает)

12:00 | Клиент: Дмитрий
      | Услуга: Стрижка + Борода
      | Статус: [ ОТМЕНИТЬ ] [ ВЫПОЛНЕНО ]
(При нажатии загорается красным цветом, "выполнено" пропадает)

15:00 | Клиент: Ольга
      | Услуга: Окрашивание

      | Статус: [ ОТМЕНИТЬ ] [ ВЫПОЛНЕНО ]


                  (При нажатии загорается серым цветом)
                  [ + ЗАКРЫТЬ ВРЕМЯ (ПЕРЕРЫВ) ]
