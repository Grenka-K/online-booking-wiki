# 📝 02. Спецификация требований

Здесь собраны формализованные требования к системе, составленные на основе проведенного анализа. Документы структурированы в соответствии с **ГОСТ 34.602-2020** и методологией **ISO/IEC/IEEE 29148**.

### 📂 Файлы в этой папке:

| Файл | Описание |
| :--- | :--- |
| 📄 **`Классификация требований.docx`** | Разделение требований на уровни (Бизнес, Пользовательские, Функциональные, Нефункциональные). Приоритезация по MoSCoW. Бизнес-правила и ограничения. |
| 📄 **`Usestories.docx`** | Пользовательские истории по стандарту INVEST, критерии приемки (Acceptance Criteria) и детальные Use Cases с альтернативными потоками. |
| 📄 **`Спецификация требований.docx`** | Черновик Технического Задания (ТЗ) и Матрица трассировки требований (RTM). |

### 🎯 Ключевые особенности:
*   Всего сформулировано **20 функциональных** и **16 нефункциональных** требований.
*   Приоритет **Must** строго ограничен 60% (12 из 20) для обеспечения реализуемости MVP.
*   Все требования проверены на соответствие критериям качества ISO 29148 (однозначность, проверяемость, трассируемость).
