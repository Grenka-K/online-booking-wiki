##  ER-диаграмма (Модель данных)
```mermaid
erDiagram
    КЛИЕНТ ||--o{ ЗАПИСЬ : "создаёт"
    МАСТЕР ||--o{ ЗАПИСЬ : "ведёт"
    УСЛУГА ||--o{ ЗАПИСЬ : "входит в"
    МАСТЕР ||--|| РАСПИСАНИЕ : "имеет"
    ЗАПИСЬ ||--o{ УВЕДОМЛЕНИЕ : "порождает"
    ЗАПИСЬ ||--o| ОТЗЫВ : "получает"

    КЛИЕНТ {
        int ID_Клиента PK
        string ФИО
        string Телефон
        bool Согласие_ПД
    }
    МАСТЕР {
        int ID_Мастера PK
        string ФИО
        string Специализация
    }
    УСЛУГА {
        int ID_Услуги PK
        string Название
        decimal Цена
    }
    ЗАПИСЬ {
        int ID_Записи PK
        int ID_Клиента FK
        int ID_Мастера FK
        datetime Дата_Время
        string Статус
    }
    РАСПИСАНИЕ {
        int ID_Расписания PK
        int ID_Мастера FK
        date Дата
    }
    УВЕДОМЛЕНИЕ {
        int ID_Уведомления PK
        int ID_Записи FK
        string Тип
    }
    ОТЗЫВ {
        int ID_Отзыва PK
        int ID_Записи FK
        int Оценка
    }
```
##  DFD (Диаграмма потоков данных)
```mermaid
flowchart LR
    K[Клиент]
    A[Администратор]
    
    P1[1. Проверка слотов]
    P2[2. Создание записи]
    P3[3. Перенос / отмена]
    P4[4. Отправка уведомлений]
    
    H1[(Х1. Записи)]
    H2[(Х2. Расписание)]
    
    K -->|запрос| P1
    P1 -->|слоты| K
    K -->|данные| P2
    P2 -->|подтверждение| K
    
    P1 -->|проверка| H2
    H2 -->|занятые слоты| P1
    
    P2 -->|новая запись| H1
    P2 -->|бронирование| H2
    
    A -->|запрос| P3
    P3 -->|обновление| H1
    P3 -->|освобождение| H2
    
    P2 -->|событие| P4
    P3 -->|событие| P4
    P4 -->|push / SMS| K
    P4 -->|уведомление| A
```
##  BPMN-схемы


### BPMN 1. Онлайн-запись клиента
```mermaid
flowchart LR
    subgraph P1[ПУЛ: КЛИЕНТ]
        direction TB
        S1((Старт))
        T1[Открыть сайт]
        T2[Выбрать услугу]
        T3[Выбрать мастера]
        T4[Выбрать время]
        T5[Ввести контакты]
        T6[Подтвердить]
    end

    subgraph P2[ПУЛ: СИСТЕМА]
        direction TB
        T7[Показать каталог]
        T8[Показать мастеров]
        T9[Показать слоты]
        G1{Слот свободен?}
        G2{Двойная запись?}
        T10[Показать ошибку]
        T11[Сохранить]
        T12[Отправить уведомление]
        E1((Запись создана))
    end

    S1 --> T1
    T1 --> T7
    T7 --> T2
    T2 --> T8
    T8 --> T3
    T3 --> T9
    T9 --> T4
    T4 --> G1
    G1 -- Нет --> T9
    G1 -- Да --> T5
    T5 --> T6
    T6 --> G2
    G2 -- Да --> T10
    T10 -.-> T4
    G2 -- Нет --> T11
    T11 --> T12
    T12 --> E1
```


### BPMN 2. Перенос или отмена записи
```mermaid
flowchart TD
    subgraph P1[ПУЛ: КЛИЕНТ]
        S1((Старт))
        T1[Открыть запись]
        T2[Нажать Отменить]
    end

    subgraph P2[ПУЛ: СИСТЕМА]
        G1{Меньше 24 ч?}
        T3[Освободить слот]
        T4[Обновить расписание]
        T5[Уведомить админа]
        E1((Слот освобожден))
    end

    subgraph P3[ПУЛ: АДМИНИСТРАТОР]
        G2{Разрешить?}
        T7[Согласовать]
        T8[Отклонить]
        T9[Уведомить клиента]
        E2((Клиент уведомлен))
    end

    S1 --> T1 --> T2 --> G1
    G1 -- Да --> T3 --> T4 --> E1
    G1 -- Нет --> T5 --> G2
    G2 -- Да --> T7 --> T9
    G2 -- Нет --> T8 --> T9
    T9 --> E2
```


### BPMN 3. Управление расписанием администратором
```mermaid
flowchart TD
    subgraph P1[ПУЛ: АДМИНИСТРАТОР]
        S1((Старт смены))
        T1[Открыть расписание]
        G1{Какое действие?}
        T2[Подтвердить]
        T3[Перенести]
        T4[Отменить]
        T5[Закрыть слот]
        T6[Сформировать отчёт]
    end

    subgraph P2[ПУЛ: СИСТЕМА]
        T7[Обновить статус]
        T8[Пересчитать слоты]
        T9[Заблокировать слот]
        T10[Сформировать отчёт]
        T11[Отправить уведомления]
        E2((Данные обновлены))
    end

    S1 --> T1 --> G1
    G1 -- Подтвердить --> T2 --> T7
    G1 -- Перенести --> T3 --> T8
    G1 -- Отменить --> T4 --> T8
    G1 -- Перерыв --> T5 --> T9
    G1 -- Отчёт --> T6 --> T10
    
    T7 --> T11
    T8 --> T11
    T9 --> T11
    T10 --> E2
    T11 --> E2
```


### BPMN 4. Интеграции и уведомления

    G1 -- Да --> T2

    T4 --> T8

    T8 --> T6
