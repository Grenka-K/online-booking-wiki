# 🏗️ 03. Архитектура и модели данных

Раздел содержит визуальные артефакты, описывающие структуру, логику работы и потоки данных проектируемой системы. 

### 📂 Файлы в этой папке:

| Файл | Описание |
| :--- | :--- |
| 📄 **`schemes.md`** | Markdown-файл с исходным кодом диаграмм (Mermaid). 

### 🗺️ Какие модели здесь представлены:
*   **BPMN:** Схемы бизнес-процессов (Онлайн-запись, Отмена, Работа администратора, Интеграции).
*   **DFD (Data Flow Diagram):** Логическая модель движения данных между процессами и хранилищами.
*   **ER-диаграмма (Crow's Foot):** Модель сущностей базы данных с атрибутами и кардинальностью связей.

> 💡 *Подсказка: Для просмотра красиво отрендеренных схем в удобном формате переходите в раздел **Wiki проекта** (ссылка в корне репозитория).*
