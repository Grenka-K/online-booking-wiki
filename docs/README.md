# 📚 Документация проекта

В этой папке собраны все исходные материалы проекта «АС Онлайн-запись в парикмахерской».

### 📂 Структура папок:

*   📁 **[01_Analysis](./01_Analysis)** — Анализ предметной области: карта стейкхолдеров, гайды интервью, анкеты и дерево функций (декомпозиция).
*   📁 **[02_Requirements](./02_Requirements)** — Работа с требованиями: User Stories, Use Cases, классификация требований и черновик ТЗ по ГОСТ.
*   📁 **[03_Architecture](./03_Architecture)** — Архитектурные схемы (BPMN, ER, DFD), карта ролей и матрица доступа.
