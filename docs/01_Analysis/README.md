# 🔍 01. Предпроектный анализ и исследование

Этот раздел содержит результаты исследования предметной области. Здесь собраны данные, которые легли в основу всех дальнейших требований.

### 📂 Файлы в этой папке:

| Файл | Описание |
| :--- | :--- |
| 📄 **`stackholder.docx`** | Карта стейкхолдеров, матрица «Влияние/Интерес» и сравнительная таблица методов исследования. |
| 📄 **`stackholder2.docx`** | Сырые данные: гайды полуструктурированных интервью (Владелец, Админ, Разработчик) и анкеты (Клиенты, Мастера). |
| 📄 **`decomposition.docx`** | Дерево функций системы, а также концептуальные схемы (BPMN, DFD, ER-диаграмма). |

### 🛠️ Использованные методы:
*   **Качественные:** Глубинное интервью (для выявления скрытых болей бизнеса).
*   **Количественные:** Анкетирование (для сбора статистики по клиентам и мастерам).
*   **Моделирование:** Функциональная декомпозиция.
